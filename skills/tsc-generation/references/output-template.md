# Output Template

Always output only the `Test Specification Case` table.

Do not output input analysis, function decomposition, field matrix, CRUD matrix, coverage matrix, boundary matrix, test data design, risk priority, regression checklist, quality gate, or other narrative sections as separate deliverable sections.

If evidence is missing or conflicting, keep the note concise inside the relevant testcase row, for example in `Pre-condition`, `Expected Result`, or `Comment`, using `NOT FOUND IN DOCUMENT` when needed.
